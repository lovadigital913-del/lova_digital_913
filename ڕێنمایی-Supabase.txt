پەکێجی دەستپێکی نوێی Lova Digital

ئەم وەشانە بە Supabase و GitHub ـی نوێ دەبەسترێتەوە و بە نموونەی بەتاڵ دەست پێ دەکات. پاش چوونەژوورەوە، نموونە و پلاتفۆرمەکانی خۆت لە بەڕێوەبردن زیاد بکە؛ گۆڕانکارییەکان بۆ هەموو سەردانکەران لە Supabase پاشەکەوت دەبن.

١) لە Supabase > SQL Editor فایلە supabase-setup.sql جێبەجێ بکە.
٢) لە Supabase > Storage، bucket ـێکی Public بە ناوی lova-images دروست بکە.
٣) لە Authentication > Users > Add user، هەژماری lovadigital913@gmail.com بە وشەی نهێنی خۆت دروست بکە.
٤) هەموو فایلەکانی ئەم پەکێجە لە ڕووتی GitHub repository ـەکەت بار بکە و Commit changes بکە.
٥) دوای بڵاوکردنەوە، ماڵپەڕەکە بکەرەوە؛ لە بەڕێوەبردن بە ئیمەیڵ و وشەی نهێنی بچۆ ژوورەوە، پاشان نموونە و پلاتفۆرمەکان زیاد بکە.

بەشی بەڕێوەبردن: بە خێرایی پێنج جار کلیک لە لۆگۆ بکە یان #admin لە کۆتایی ناونیشانی ماڵپەڕ زیاد بکە.
تێبینی: SQL تەنها یەک جار جێبەجێ بکە. Secret/service_role key مەخە ناو فایلەکان؛ تەنها Publishable key بەکاربهێنە.
